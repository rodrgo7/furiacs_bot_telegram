# FURIA CS Fans Landing Page

Uma landing page moderna e responsiva para os fãs do FURIA CS, fornecendo acesso rápido a recursos importantes e links para a comunidade.

## Recursos
- Design moderno e responsivo
- Links diretos para o bot do Telegram
- Acesso rápido às notícias do time
- Visualização de partidas recentes
- Informações sobre ranking
- Links para redes sociais oficiais

## Estrutura do Projeto
```
landpage/
├── css/
│   └── styles.css
├── img/
│   ├── Furia-logo-redondo.png
│   └── brasil.jpg
└── index.html
```

## Tecnologias Utilizadas
- HTML5
- CSS3
- Font Awesome (para ícones)
- Design responsivo

## Como Usar
1. Clone o repositório
2. Abra o arquivo `index.html` em seu navegador
3. Para desenvolvimento, você pode usar qualquer servidor web local
